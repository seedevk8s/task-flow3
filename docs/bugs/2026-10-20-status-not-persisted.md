# 완료 상태가 새로고침 뒤 유지되지 않음

> 검수 절차 시연을 위해 의도적으로 심은 버그. 이슈 #2, 커밋 `0826984`에서 해결됨.

- 원인: 상태 변경이 `PATCH /api/tasks/{id}/status` 가 아닌 `PATCH /api/tasks/{id}` 로 전송되어 저장되지 않았다. 화면은 응답을 기다리지 않고 먼저 갱신해서 문제가 가려졌다.
- 해결: 올바른 경로로 호출하고, 서버가 돌려준 값으로 화면을 갱신한다.

## 재현 순서
1. 카드의 상태를 '완료'로 바꾼다 (카드가 완료 열로 옮겨 보인다)
2. 페이지를 새로고침한다 (F5)

## 기대 결과
카드가 완료 열에 남는다 (R-002 「바꾼 상태는 유지된다」)

## 실제 결과
카드가 원래 열로 돌아간다

## 증거
화면 캡처 2장(F5 전 · 뒤), 브라우저 Network 탭의 PATCH — 보낸 값과 돌아온 값
PATCH /api/tasks/1  보낸 값 {"status":"DONE"}  응답 200 "status":"TODO"
